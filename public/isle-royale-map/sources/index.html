Source strategy

The planner keeps discovery, geometry and authority separate.

NPMaps = completeness checklist

The NPMaps Isle Royale collection is useful because it exposes the breadth of available map products. It is not treated as the authoritative feature database.

View NPMaps Isle Royale collection

NPS = current visitor authority

The current NPS Maps & Brochures hub remains the handoff for park guides, boating maps, off-trail camping and trail mileage.

Open current NPS map resources

Federal GIS = deep layers

Geology and vegetation use actual federal GIS rather than traced brochure pixels. Relief comes from the keyless USGS The National Map shaded-relief service, while older science layers keep their original vintage visible.

Machine-readable source desk

Every major map family has a destination.

“Live” means the browser can currently request vector features. “ETL-ready” means the source is resolved to real GIS but belongs in the normalized tile pipeline before it should be turned on as a large web layer. The complete machine-readable manifest is also available as raw source catalog JSON.

Geologyresearch-onlyNational Park Service Geologic Resources InventoryNPS GRI digital release 2021; older source mapping. Generated from the NPS GRI GeoPackage: 1,975 geologic-unit features, reprojected and simplified for web use. Manifest records SHA-256 and source accuracy caveat; not survey-grade. Retained in the source/research catalog but intentionally removed from the trip-planning layer controls because it does not improve route decisions.

Retained in the source/research catalog but intentionally removed from the trip-planning layer controls because it does not improve route decisions.
